# 精灵分析的刷新与缓存

“精灵分析”位于“精灵详情”“原始数据”旁。三页、兑换商店和资产使用同一份战力与培养事实，不在界面各算一套。

| 触发 | 查询游戏 | 本地计算与显示 |
| --- | --- | --- |
| 点击背包/仓库中的精灵 | 在线时查询这一只 | 先显示缓存；有效新详情就绪后更新这一只的分析 |
| 切到精灵分析 | 不查询 | 读取当前已准备结果，缺失则走已有本地详情准备链 |
| 排序、筛选、翻页、程序重新定位 | 不查询详情 | 复用相同数据版本的结果 |
| 手动刷新仓库详情 | 按勾选时代查询 | 每只有效返回后按记录版本计算，重复任务合并 |
| 失败、断网、数据未齐 | 不额外自动补请求 | 保留同账号、同精灵上次分析和原数据时间；缺项显示未知 |
| 检查数据更新 | 只取官方公共资源 | 更新的字典/职业/星神/星轮规则使旧分析失效，使用本地详情重新准备 |
| 资产“重新计算养成分析（仅本地）” | 不查询 | 复用已算单只结果，补读本地详情，生成全账号汇总与建议 |
| 资产“统计本地红星” | 不查询 | 独立扫描当前账号磁盘详情，统计普通/万变红星的已装备及本宠背包数量；不写缓存、不触发养成分析 |
| 精灵分析顶部“刷新材料背包” | 并行查询道具与空闲源兽仓库 | 材料数量唯一手动更新入口；两组独立更新需要/已有/还差数量，不重新请求精灵详情或兑换次数 |

单只战力事实按账号、会话、实例、详情版本、官方元数据版本和算法版本复用。换账号或切换精灵时不保留前一只的分析。
新结果准备期间保留当前精灵已有分析，并明确标为上一份数据；完整新结果到达后一起替换。
显示的“数据时间”是详情的观测/缓存时间，不把打开页面的时间当成数据更新时间。

精灵分析直接列出尚未完成的元魂等级/觉醒、源兽星级和阶级、星轮点亮、普通红星和万变红星缺口；只有灵初精灵显示星轮突破及突破后的星灵装备待办。神运、星迹、启元等非灵初精灵不显示突破状态或缺口，时代未知时也不把它显示成“未突破”。时代优先使用同种族官方标记，避免皮肤名导致误判。不展示词条解释和逐槽星神分析。
所需材料只展示对应元魂、对应源兽及星轮精华；同种材料先合并需求，再与材料背包比较。需要量与背包已有量分别展示，还差量为两者差额（最低为零）。
材料背包未读取时显示“未读取”；有效缓存可以离线显示，刷新失败保留原数量及时间。一次材料刷新并行发送 `MaterialExtension / 3_11 / {}` 与 `PJXExtension / 2_32_0 / null`。元魂和精华来自前者 `4` 分组，源兽来自后者空闲仓库 `eps` 的 `dpi/exp/lvl/eqn` 堆叠记录。源兽按对应 `sourceId` 合计各等级可用数量，不混入精灵身上正在使用的源兽；培养成本里的 `extra=1` 不限制只能使用一级源兽。明确空仓库为已知 0，缺失、坏包或超时只保留该组旧观察。
“刷新材料背包”固定在精灵分析页顶部，未选精灵、没有材料缺口或滚动正文时都能看到。打开页面、选择精灵和刷新商店都不会顺带更新这份材料观察。
材料观察保存在账号目录的 `cultivation-materials.json`，使用 schema 2 和源兽来源标识 `2_32_0.eps-warehouse`。更新覆盖原文件，换账号时清空内存显示；两个查询都结束后退出刷新状态。旧 schema 1 的道具数量可以恢复，旧通用 `24` 数量不作为可消费源兽显示，等待一次手动仓库查询。这份只读观察不改变商店兑换或游戏写操作权限。详见 [源兽材料背包读取](source-beast-inventory-protocol.md)。

当前派生算法版本为 10。旧算法产生的派生索引失效，原始精灵详情和图片继续保留，重新计算不需要联网。
派生索引仍是按实例覆盖的可重建缓存，删除某只详情时同步删除它的派生文件；已经打开的内存内容可能保留到重新刷新或下次启动。

商店即时复用当前版本的单只需求事实。缺少星神、已有但未装、槽位需升级和万变栏缺口分别判断；不会把已有红星重复推荐为需要获取。
精灵列表“战斗力/极限战斗力”仅在本地 `current` 与 `highest` 都已知且 `current >= highest` 时追加“（至高）”；低于目标或数据未知时不追加后缀。`current` 沿用实际槽位等级下、包含本宠星神背包的合法持有配置，不以官方 `xzdl` 作为至高判断线。详情刷新后，后缀随同一份事实更新或移除。
培养需求可从有效只读/离线详情计算。账号材料和兑换次数仍按其各自来源、观测时间与周期判断，不能因战力可计算就当成材料已够或次数有效。

“检查数据更新”同时发现当前官方注册表、HUD、近期发布及显式链接中的活动兑换目录。2026-09-13 的公开资源验证覆盖本次发现的 8 个活动目录、72 个项目；覆盖范围以当次报告为准，未保证所有历史活动或尚未识别的结构。独立活动按来源隔离，活动次数及动态价格在对应活动内查看，不套用主商店次数。活动目录更新使用公共资源，详见 [限时活动指定精灵兑换目录](activity-exchange-public-data.md)。

资产全账号汇总保持现有手动计算入口，避免每次选宠都重跑全部商品匹配。详情或规则改变时标记旧汇总需要更新；重算后展示至高培养、实际获取缺口、已有装备待调整和槽位升级等独立项目。

“统计本地红星”与养成汇总分别触发。统计包含当前账号磁盘详情中的已装备星神和该精灵自己的星神背包，分别列出普通红星、万变红星以及二者的已装备/背包颗数。背包重复 ID 按颗数保留；万变映射与底座只计一颗，嵌套精灵不重复扫描。该操作支持取消，显示扫描、跳过、去重和资料不全数量，不联网、不写缓存，不因本地统计完成就声称未缓存的精灵也已覆盖。
